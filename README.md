# Rally Point

Offline-first badminton tournament manager (PWA).

Run tournaments end to end: enroll players and referees, age categories (U14/U18/…),
on-the-spot team draws with a ceremony animation, configurable formats (round robin,
groups + knockout, knockout), live court scoring with real service rotation, a projector
display, Excel and PDF exports, and role-based sign-in (admin / organizer / scorer / viewer).

**Use it:** open the GitHub Pages site, then "Add to Home Screen" — it installs and works
fully offline. Default sign-in: `admin` / `admin123` (change it in Users).

All data is stored locally in the device's browser — nothing leaves the device.
